# ইউনিয়ন ভোটার তালিকা: ৯টি গ্রামের ফোল্ডার কাঠামো ও গিটহাব ব্যবহারের নিয়ম

প্রতিটি গ্রামের জন্য আলাদা আলাদা ফোল্ডার রয়েছে। মোট ৯টি গ্রামের ফোল্ডার তৈরি করে রাখা হয়েছে:

│   ├── male.json       -> পুরুষ ভোটারের তালিকা
│   └── female.json     -> মহিলা ভোটারের তালিকা
│
├── cotobadura/          -> ছোট বাদুরা গ্রাম

│   ├── male.json       -> পুরুষ ভোটারের তালিকা

### ১. ফোল্ডারের নাম পরিবর্তন ও নতুন গ্রাম যোগ করার নিয়ম:
1. আপনি আপনার ইচ্ছামতো ফোল্ডারের নাম পরিবর্তন (Rename) করতে পারবেন (যেমন: `village_3` এর বদলে `amrajuri` বা যেকোনো ইংরেজি নাম)।
2. ফোল্ডারের ভেতরে থাকা `info.json` ফাইলে আপনার গ্রামের বাংলা নাম লিখে দেবেন:
   ```json
   {
     "name": "আপনার গ্রামের বাংলা নাম"
   }
   ```
3. `male.json` ফাইলে সেই গ্রামের পুরুষ ভোটারদের JSON ডাটা পেস্ট করবেন।
4. `female.json` ফাইলে সেই গ্রামের মহিলা ভোটারদের JSON ডাটা পেস্ট করবেন।

### ২. ভোটারের JSON ফাইলের ফরম্যাট (`male.json` বা `female.json`):
```json
[
  {
    "serialNo": "১",
    "name": "মো: আব্দুল জলিল",
    "dob": "০১/০১/১৯৮০",
    "fatherName": "মো: কাশেম",
    "motherName": "আমেনা বেগম",
    "profession": "কৃষক",
    "voterId": "1980000000001",
    "address": "গ্রামের নাম, মোড়েলগঞ্জ"
  }
]
```
*(নোট: `male.json` এ আপলোড করলে অ্যাপ স্বয়ংক্রিয়ভাবে `"পুরুষ"` হিসেবে শনাক্ত করবে এবং `female.json` এ আপলোড করলে `"মহিলা"` হিসেবে শনাক্ত করবে।)*

### ৩. গিটহাবে আপলোড করার পর অ্যাপে কীভাবে ডাটা রিড করবে?
- আপনি যখন GitHub-এ কোনো ফোল্ডারের `male.json` বা `female.json` ফাইলে ডাটা আপলোড বা পরিবর্তন করবেন, অ্যাপটি সার্ভার এবং স্ট্যাটিক (GitHub Pages) উভয়ভাবেই স্বয়ংক্রিয়ভাবে সেই ফোল্ডারগুলো থেকে ডাটা রিড করবে।
