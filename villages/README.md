# গ্রাম ও ভোটার তালিকা যোগ করার নিয়ম

এখন আপনি প্রতিটি গ্রামের জন্য একটি ফোল্ডার এবং তার ভেতর পুরুষ ও নারীদের জন্য আলাদা দুটি JSON ফাইল রাখতে পারবেন।

### ১. ফোল্ডারের গঠন (Folder Structure)

`villages` ফোল্ডারের ভেতর (অথবা সরাসরি প্রজেক্টের রুটে) গ্রামের নামে একটি ফোল্ডার তৈরি করুন। যেমন: `pathamara`:

```text
villages/
└── pathamara/
    ├── info.json      (গ্রামের আসল নাম)
    ├── male.json      (পুরুষ ভোটার তালিকা)
    └── female.json    (নারী ভোটার তালিকা)
```

---

### ২. ফাইলগুলোর বিবরণ:

#### ক. `info.json`
এখানে গ্রামের নাম বাংলায় লিখুন:
```json
{
  "name": "পাঠামারা"
}
```

#### খ. `male.json` (পুরুষ ভোটার)
সকল পুরুষ ভোটারের তালিকা:
```json
[
  {
    "serialNo": "১",
    "name": "মো: আব্দুল জলিল",
    "dob": "০১/০১/১৯৮০",
    "fatherName": "মো: কাশেম",
    "motherName": "আমেনা বেগম",
    "profession": "কৃষক",
    "voterId": "1980000000001",
    "address": "পাঠামারা, মোড়েলগঞ্জ"
  }
]
```
*(এখানে `"gender": "পুরুষ"` স্বয়ংক্রিয়ভাবে অ্যাপ নিজে থেকেই যুক্ত করে নেবে)*

#### গ. `female.json` (নারী ভোটার)
সকল নারী ভোটারের তালিকা:
```json
[
  {
    "serialNo": "২",
    "name": "মোসা: রহিমা খাতুন",
    "dob": "০৫/০৫/১৯৮৫",
    "fatherName": "মৃত রহিম শেখ",
    "motherName": "মরিয়ম বেগম",
    "profession": "গৃহিণী",
    "voterId": "1985000000002",
    "address": "পাঠামারা, মোড়েলগঞ্জ"
  }
]
```
*(এখানেও `"gender": "মহিলা"` স্বয়ংক্রিয়ভাবে অ্যাপ নিজে থেকেই যুক্ত করে নেবে)*

---

### ৩. ফাইল সংরক্ষণের সাথে সাথে স্বয়ংক্রিয় লোড:
সার্ভার স্বয়ংক্রিয়ভাবে এই ফাইলগুলো পড়ে নেবে। `search.html` ফাইলে কোনো কোড এডিট করার প্রয়োজন নেই!
